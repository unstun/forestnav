面向密集森林环境的 Oracle 监督子目标分解 Hybrid A* 规划

Oracle-Supervised Subgoal Decomposition for Hybrid A* Planning in Dense Forest Environments
ForestNav 项目 · F-N3P 设计稿 v1.1
草稿日期：2026-06-20 · 状态：设计审阅阶段，Research Contract 未立
实验结果以 [待填充] 标注
摘要 在密集森林环境中为阿克曼转向车辆规划长距离、满足运动学约束的路径时，原版 Hybrid A* 面临节点扩展数急剧增长的问题。本文提出一种 oracle 监督的子目标分解方法（oracle-supervised subgoal decomposition），从先验占据栅格图中学习逐步预测中间 SE(2)（特殊欧氏群）子目标。基于 KNN 的预测器在成功的 Hybrid A* 解上训练，将每个规划查询分解为一系列短段。各段由带解析扩展的 Hybrid A* 连接，保证最小转弯半径与完整车体碰撞约束。三级回退阶梯确保方法继承原版 Hybrid A* 的完备性。 [待填充：关键定量结果——规划时间缩减比例、成功率、路径膨胀率]

1  引言

森林地形中的自主导航要求规划满足阿克曼转向运动学约束的无碰撞路径——尤其是最小转弯半径和不可忽略的车体足迹。当环境以先验占据栅格（分辨率 0.1 m，典型工作区约 30 × 30 m）表示时，带 Reeds-Shepp 解析扩展的 Hybrid A* 是自然选择：它在 SE(2) 状态空间上搜索，同时保证运动学可行性。

然而，原版 Hybrid A* 存在众所周知的扩展性问题。随着起终点欧氏距离增大和障碍密度增高，扩展节点数急剧增长——经常超出计算预算、导致规划超时。在密集森林中这一问题尤为突出：狭窄的树缝迫使路径反复绕行和换向。

设计决策 D1 放弃"缝枚举 A+C 混合"方案，选择 N3P 忠实路线的逐步预测。Dr Sun 2026-06-12 知情拍板。

我们的核心观察是：森林中成功的 Hybrid A* 解可以被分解为一系列短段，每段都可以用一条 Reeds-Shepp 曲线或一个短距离有界搜索来连接。如果一个预测器能够识别这些中间子目标——仅需当前位姿、目标位置和局部障碍几何信息——那么一个长距离困难查询就被缩减为一系列简单的短程子查询。

本方法（内部代号 F-N3P）将 Xue 等人 N3P 的准备位姿预测从单瓶颈泊车场景扩展到多瓶颈的森林规划。方法分两个阶段：

  • 离线阶段：用原版 Hybrid A* 求解大量森林规划查询。通过贪心 RS 可达分段规则从成功路径中提取有序子目标序列。构建 (特征, 相对位姿) 样本对的 KNN 库。
  • 在线阶段：对每个新查询，通过 KNN 查表逐步预测子目标，用有界 Hybrid A* 连接相邻子目标对，拼接各段。预测失败时回退至原版 Hybrid A*。

贡献。（1）我们形式化了一种面向密林 Hybrid A* 的逐步子目标分解方法——通过贪心 RS 可达分段定义，将 N3P 的单位姿预测扩展为有序 SE(2) 子目标序列。（2）我们设计了 41 维手工特征表示（射线投射距离剖面 + 目标相对量 + 密度统计）作为森林场景的环境抽象，替代结构化泊车的 4 参数闭式抽象。（3）我们提供了全面的实验评估，包括规则分解基线对比、标签规则与特征的消融研究、以及在未见程序化地图和真实 SLAM 占据图上的泛化测试。

2  相关工作

学习引导格搜索/混合规划器。 N3P [Xue 等, ITSC 2026] 学习泊车的单个准备位姿，将机动分解为准备-接近-入位三阶段后交给 Hybrid A* 消费。本工作继承 N3P 的自监督标签哲学、KNN 模型和公平计时纪律，但将预测从单个位姿扩展到有序序列，并用通用特征表示替代泊车闭式抽象。Bonetti 等人的 Waypoints Hybrid B* 从拓扑路线图生成 waypoint 引导工业走廊搜索——waypoint 来自规则/拓扑图而非学习，且环境是结构化的。Banzhaf 等人学习位姿样本指导 Bi-RRT* 采样——这是 informed sampling 而非有序子目标分解，底层规划器也不同。

学习子目标规划。 Stein 等人的 Learned Subgoal Planner (LSP) 学习前沿属性（死端概率）辅助未知环境中的导航决策——这是探索阶段的决策辅助，不是已知地图上带运动学约束的运动级规划器。层次化强化学习方法（HIRO、HAC）将子目标作为策略内部机制，而非几何规划器消费的显式中间位姿。

引用纪律 Bonetti、LSP 等论文引用前须走核查四步，禁凭 AI 记忆生成 BibTeX。

Hybrid A* 与 Reeds-Shepp 曲线。 Hybrid A* [Dolgov 等, IJRR 2010] 在离散栅格上搜索 SE(2) 状态，利用 Reeds-Shepp 曲线 [Reeds & Shepp, 1990] 作为解析扩展加速目标连接。本方法对教师数据生成和在线段内连接使用同一份 Hybrid A* 实现，确保公平对比。

3  问题形式化

环境。工作区 W ⊂ ℝ² 按分辨率 r = 0.1 m 离散为栅格集 G。先验占据栅格图 M : G → {0, 1} 对树障占据的栅格赋值 1；占据区域记为 Occ(M) ⊂ W。地图约 30 × 30 m，离线已知。"先验"限定语将本设定与未知环境探索类工作划界。

车辆。车辆状态 x = (p, θ) ∈ SE(2)。阿克曼底盘施加路径曲率约束 |κ| ≤ 1/ρmin，其中 ρmin 为最小转弯半径。车体足迹 B(x) ⊂ ℝ² 以双圆近似覆盖（用两个圆包络车体足迹，轴距约 0.6 m）。

Xfree = { x ∈ SE(2) : B(x) ∩ Occ(M) = ∅ } (1)

可行路径 τ : [0, 1] → Xfree 分段光滑、处处满足曲率约束、允许有限次方向切换。

规划查询。给定 q = (M, xs, xg)，求可行路径 τ 使得 τ(0) = xs，τ(1) = xg。求解质量两维度：搜索代价（规划时间 T、节点扩展数 E）和路径质量（长度、方向切换次数、最小安全裕量）。痛点：原版 Hybrid A* 的 E 随距离和障碍密度急剧增长。

Reeds-Shepp 记号。RS(x, x′) 表示连接两位姿的最短 RS 曲线，按构造满足曲率约束。可行性仅需碰撞检测：RSfree(x, x′) ⇔ 曲线全程位于 Xfree，实现为沿曲线按分辨率 r 采样做双圆碰撞检测。

子目标分解。给定查询 q，求有序子目标序列 (g1, …, gK)，gi ∈ Xfree，使相邻对 (gi, gi+1) 可被低代价连接——理想情况用无碰撞 RS 曲线直连，一般情况用预算内的短段 Hybrid A*。完整路径为拼接 τ = τ0 ⊕ τ1 ⊕ … ⊕ τK。

4  方法

4.1  系统总览

离线（一次性） 在线（每个查询） ───────────────────────────────── ───────────────────────────── ① 程序化森林批量生成 当前位姿 p ← 起点 ↓ (maps/forest.py) │ ② HA*+RS 全程求解，保留成功路径 ├― 停止判据：RSfree(p → 终点)？ ↓ (pathplan) │ 是 → RS 直连终点，输出 ✓ ③ 前向贪心 RS 分段 │ 否 ↓ → 子目标真值序列 ├― 特征提取 f(p; 终点, 地图) ↓ (算法 1) ├― KNN 查库 → 下一子目标 ğ ④ 特征化 → (特征, Δ位姿) 样本对 ├― 可行性校验：RSfree(p→ğ)？ ↓ │ 否 → 回退 F1/F2/F3 (§4.6) ⑤ 构建 KNN 库 / 训练 MLP ├― 段内 HA*(p→ğ)，解析扩展优先 └― p ← ğ，循环（上限 Kmax 步）

学习模块只回答一个问题："站在当前位姿、目标在那边、局部树障长这样——下一个该到达的中间位姿在哪？"这就是 N3P 的问题，反复调用后形成序列。

与 N3P 对比 N3P 预测 1 个准备位姿（泊车单瓶颈）。我们逐步调用同一预测器形成序列（森林多瓶颈）。标签哲学、KNN 模型、fallback 策略继承自 N3P。

4.2  离线标签提取：前向贪心 RS 可达分段

给定成功的教师路径 P : [0, S] → Xfree（弧长参数化，P(0) = xs，P(S) = xg），通过在每步贪心地寻找最远 RS 可达点来提取有序子目标序列：

算法 1  前向贪心 RS 可达分段（标签提取）
输入：教师路径 P : [0, S] → Xfree（弧长参数化）
输出：子目标序列 (g1, …, gK) 及样本集 {(f(gi), Δi)}
参数：Lmax = 8 m（段长上界），Lmin = 1.5 m（单步推进下界）
g0 ← P(0); s0 ← 0; i ← 0
while ¬( RSfree(gi, xg) ∧ len(RS(gi, xg)) ≤ Lmax ):
Si ← { s ∈ (si, S] : RSfree(gi, P(s)) ∧ len ≤ Lmax }
if Si = ∅ or max(Si) − si < Lmin:
fail_count += 1; 丢弃 P; return ∅ ▹ 标签失败
si+1 ← max(Si); gi+1 ← P(si+1) ▹ 取最远 RS 可达点
Δi ← gi+1 ⊖ gi ▹ gi 车体系下的相对位姿
输出样本 (f(gi), Δi); i ← i + 1
K ← i ▹ 末段：RS 直连终点，不产样本

语义。每个子目标都是沿教师路径、从上一子目标出发、一条无碰撞 RS 曲线能到达的最远点。这是 N3P"解析扩展成功点"标签的序列化推广：N3P 有一个这样的点（瓶颈处），森林有许多个。

构造性质。按构造，对每个 i，RSfree(gi, gi+1) 成立。推论：在教师分布内、同一静态地图上，在线段内连接的解析扩展首次即可命中——Hybrid A* 仅作保险。当实际位姿偏离 gi 后该性质退化为近似，退化程度由子目标可达率量化（§5）。

失败处理。第 4–5 行：若最远可达点的推进距离不足 Lmin = 1.5 m，则丢弃整条教师路径。这防止在密集区域产生碎片化标签。标签失败率是 pilot 实验的监测指标。

样本产出。每条教师路径产出 K 个样本 (f(gi), Δi)，其中 Δi 在 gi 车体系下表达——使特征-标签对对全局 SE(2) 变换不变，这是跨地图泛化的前提。

已知风险 此规则的标签落点常在开阔地（RS 可达区域自然远离瓶颈），与局部几何特征的关联弱于瓶颈规则。若 KNN 学不动，标签 ablation 会暴露此问题。

4.3  特征设计：森林环境抽象

N3P 的泊车抽象使用 4 个闭式参数（车道宽、车位宽、死端深、类型），这在规则的泊车几何中可行。森林环境的障碍不规则、分布全程，不存在这种低维结构。我们设计 41 维手工特征向量 f ∈ ℝ41，全部在当前位姿车体系下定义：

终点方位 (sin α, cos α)，α = 目标在车体系的方位角 2 sin/cos 回避角度回绕不连续
终点朝向差 (sin Δθg, cos Δθg)，Δθg = θg − θ 2 末段姿态对齐信号

射线投射距离剖面（ray-cast clearance profile）是核心组件。具体做法是：从当前位姿向周围 32 个均匀分布的方向各发射一条射线，记录每条射线碰到最近障碍物（树干）的距离。这是在已知的占据栅格图上做的纯几何计算——不涉及任何传感器。树缝在这组距离值中表现为相邻方向上的距离突增（因为射线穿过了缝隙），KNN 的距离度量可以自然感知这些模式，无需显式检测树缝。这组特征向量就是我方的"环境抽象（environment abstraction）"——对应 N3P 的 4 参数泊车场景抽象，是贡献点之一。

术语红线 "射线投射距离剖面" ≠ LiDAR。这是先验占据栅格图上的几何查询，与传感器无关。论文中禁用"激光雷达""LiDAR""净空轮廓"描述此特征。

距离度量。训练集逐维 Z 分数标准化（z-score normalization） (μl, σl)。距离：d(f, f′) = ‖(f − f′) ø σ‖2。v1 各维等权；pilot 实验可上调终点组权重。

4.4  学习模块

主模型：KNN(k=1)。样本库 D = {(fn, Δn)}n=1N。查询特征 f 时，预测器返回 π(f) = Δn*，n* = argminn d(f, fn)。世界系子目标为 ğ = x ⊕ π(f)，其中 ⊕ 为 SE(2) 复合。

继承自 N3P 的关键性质：KNN 输出永远是教师数据中真实存在的相对位姿——它不会产生训练集中从未出现过的位姿。但这并不保证在当前地图无碰撞（样本可能来自其他地图），因此在线可行性校验仍不可或缺。

库规模。估算约 2,000 张图 × ~10 个查询 × ~6 段 ≈ 1.2 × 105 个样本。41 维 float32 约 20 MB（N3P 的 KNN 库 47.8 MB，同一量级）。KD-tree 构建 O(N log N)；41 维下 KD-tree 查询性能退化趋向线性扫描，但即便线性扫描 1.2 × 105 次 41 维距离计算也在毫秒级——不构成瓶颈。

消融模型：MLP。4 层全连接网络（约 105 参数），直接回归 Δ。已知风险：多模态平均——当存在两条可行树缝时，MLP 的均值预测落在缝间树干上。这与 N3P 中观察到的 MLP 偶发失效模式相同，由同一套可行性校验 + 回退机制兜底。

4.5  在线逐步推理

算法 2  在线逐步推理
输入：查询 q = (M, xs, xg)，样本库 D
输出：可行路径 τ（方法解或 F3 回退解）
参数：Kmax = ⌈2‖ps − pg‖/Lmin⌉，Nseg = 2000
p ← xs; τ ← ∅
for step = 1 .. Kmax:
if RSfree(p, xg): return τ ⊕ RS(p, xg) ▹ 停止判据
ğ ← p ⊕ π(f(p)) ▹ KNN 预测 + 车体系转世界系
if ¬RSfree(p, ğ): ğ ← F1(p) ▹ 第 2..k 近邻重试
if F1 全失败: 转 F2/F3 (§4.6)
τseg ← HA*(p → ğ | 解析扩展优先, 预算 Nseg) ▹ 段内连接
if τseg 失败: 转 F2/F3 (§4.6)
τ ← τ ⊕ τseg; p ← ğ
if ‖p − pg‖ 连续 2 步不降: 转 F3 ▹ 无进展哨
转 F3 ▹ 步数超限

与原版的结构对比。原版 Hybrid A* 在全程起终距离上扩展节点，扩展数随距离和密度急剧增长。本方法将这一次长搜索替换为 K 次有界短搜索（每次上限 Nseg = 2,000 次扩展）加上常数级学习开销。时间收益来自这一结构替换——这是机制陈述，由 §6 实证检验，不作先验断言。

4.6  回退阶梯与完备性

级触发条件动作
F1 RS(p → ğ) 碰撞 取 KNN 第 2..k 近邻重试（k ≤ 5）
F2 F1 全部候选失败 段内直接跑 HA*(p → ğ)，预算 Nseg；仍失败则 HA*(p → 终点) 限预算试探
F3 F2 失败 / 步数超限 / 无进展 对原查询 q 整题运行原版 HA*

完备性论证。记预算内原版 HA* 可解的查询集为 Qv。F3 规定方法失败时对原查询整题运行同配置的原版 HA*，因此方法的成功集 ⊇ Qv。即方法继承原版 Hybrid A* 的完备性级别——该完备性受分辨率和预算限制——我们不声称更强的完备性，也不声称最优性。

最坏情况开销。TF-N3P ≤ Toverhead + Tvanilla，其中 Toverhead 为逐步预测阶段全部特征/查询/校验/段内搜索耗时，受 Kmax 和各环节预算约束，有限且可控。回退触发率高意味着时间收益消失——这恰是 Contract 失败信号 №1。

Contract 草案 失败信号 №1：fallback 触发率 >30% 且时间收益消失。这是方法不 work 的最直接信号。

5  实验设计

5.1  场景生成与难度轴

训练环境为程序化生成的森林，难度由三个轴定义：

  • 树密度 λ（单位面积树数）
  • 最窄缝宽比 wmin / wveh（最窄间隙与车宽之比）
  • 起终距离 dsg（欧氏距离）

至少 3 × 3 个桶有效覆盖，遵循 N3P 的 Easy/Complex/Extreme 难度精神。各轴切点数值待 pilot 实验标定后冻结写入 Contract。

数据划分：

  • 训练：约 2,000 张程序化森林图（多密度、多种子）
  • 验证：同分布，新种子
  • 测试：(a) 未见程序化图（同分布）(b) OOD 密度桶（外推）(c) 真实 SLAM 占据图（现有 RealMap 资产，仅测试不训练）
