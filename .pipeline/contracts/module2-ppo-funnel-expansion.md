# 实验预注册：模块2 漏斗型解析扩展 (PPO + RS)

> 核心思想：针对 Hybrid A* 中 Reeds-Shepp (RS) 曲线无视障碍的痛点，采用漏斗型架构（Funnel Architecture）：中长距使用带避障基因的 PPO 策略进行虚拟 rollout 扩展，最后 1-2 米切回 RS 曲线进行完美的数学贴合（解决 BVP 震荡问题）。

## 验证与设计焦点

- **解决高频震荡问题**：利用 RS 负责最后1米收尾，规避纯学习方法的精度瓶颈。
- **平衡神经网络推理耗时与 A* 搜索效率**：端到端计算时间（含神经网络前向耗时）必须优于传统 Hybrid A*，通过减少总扩展节点数（Node Expansions）来填补网络前向的开销。

## 研究假设

在 Complex/Extreme 难度桶中（特别是极窄森林环境），PPO 漏斗型扩展相对原版 Hybrid A*（带纯 RS 解析扩展）：

1. **计算提效**：A* 总扩展节点数中位数缩减 >= 50%。
2. **端到端加速**：端到端规划时间（包含 PPO 前向推理、RS 计算与网格扩展的 Wall-clock 时间）中位数缩减 >= 30%。
3. **鲁棒性提升**：由于解析扩展成功率大幅提升，因“超时”导致的规划失败率降低 >= 20 百分点。
4. **路径质量**：最终路径的曲率连续性与平滑度不劣于原版，且路径总长膨胀 <= 5%。

以上条件须在未见程序化地图上成立。

## 成功判据

研究假设前三条必须同时成立（即速度更快，节点更少，成功率更高）。

## 失败判据（四条独立，任一命中即判失败）

1. **计算账算不平（Gate #1 命中）**：PPO 单步/多步推理耗时过大，完全吃掉了减少节点带来的时间收益（端到端时间未下降）。
2. **问题病态（Gate #2 命中）**：Oracle 全图 HA* 显示失败节点本就无解，导致任何学习型扩展都没用。
3. **最后1米对接灾难**：由于 PPO rollout 未能进入“无障碍/合适位姿”区域，末端 RS 曲线对接的成功率低于 50%，导致漏斗架构退化。
4. **奖励配置/训练不收敛（Gate #3 命中）**：在试点环境（小规模单一密度地图）下，PPO 策略到达“RS 可对接域”的成功率在规定预算内无法超越 80%。

## 实验与检验管线

- **前提**：必须先修复现有 F-N3P 的计时口径（当前 `inference.py` 中 RS 验证段耗时记为 0）。
- **指标**：逐查询配对检验（Wilcoxon signed-rank test，p < 0.05）。
- **对照组**：(1) Vanilla Hybrid A*; (2) HOPE/PAIR 范式下的简单动作掩码（若有余力）。

## 关键参数（待门控校准后冻结）

- PPO Patch 大小：局部地图感受野。
- Rollout 步长与最大步数：建议初值 step=0.3m，最大长度 1.5 倍直线距离。
- 奖励配方各项权重。
