# ForestNav Pipeline 知识库

项目知识库，结构变更须经 Conductor 角色授权（硬规则 #16）。

## 目录

| 目录 | 用途 |
|------|------|
| `contracts/` | Research Contract（实验前预注册） |
| `experiments/` | 实验台账（每轮实验一个 `.md`） |
| `literature/` | 文献库（`index.md` 为主表） |
| `survey/` | 综述库（每个调研主题一个 `.md`） |
| `terminology/` | 术语规范表 |
| `scripts/` | 辅助脚本 |
