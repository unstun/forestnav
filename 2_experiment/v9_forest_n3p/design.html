0. 一句话方案

离线：批量跑 Hybrid A*+Reeds-Shepp 拿成功路径，按「前向贪心 RS 可达分段」（Algorithm 1）切出子目标真值串，连同手工特征存进 KNN 库——标签来自规划器自己，零人工标注（主 claim 中 self-supervised 限定语的全部含义）。

在线：从起点滚动问 KNN「下一个中间位姿在哪」（Algorithm 2），Hybrid A* 只在相邻子目标间做短段搜索（解析扩展第一枪命中率按构造极高），直到终点 RS 可直达。学习承担长程分解决策，搜索保证段内运动学与车体碰撞可行。

论文主 claim（查重后收窄）：self-supervised learned route decomposition for Ackermann global planning on dense-forest prior occupancy maps——预测有序 SE(2) 子目标序列，Hybrid A* 保证段内可行性。禁写五类“首次”claim（查重报告 §5 列了反例）。

1. 任务定位与红线

任务（红线，不可动）：阿克曼小车（轴距约 0.6 m）在密林先验占据图（0.1 m 分辨率，约 30×30 m）上做离线全局规划——整图 + 起终点输入，输出整条满足最小转弯半径与完整车体碰撞约束的无碰撞路径。

痛点（实测）：vanilla Hybrid A* 长距离、密障碍下节点扩展爆炸，经常超时。

方法：学习模块滚动预测“下一个中间位姿”，Hybrid A* 只做相邻位姿间的短段搜索并拼接——学习承担长程分解决策，搜索保证段内运动学可行。

五禁 claim（查重报告 §5，均有反例）：首次学习子目标 / 首次学习加速 HA* / 首次 waypoint 引导 HA* / 首次森林 learned subgoal / 首次越野农业 HA*——论文任何位置不得出现。

学习模块只回答一个问题：“站在当前位姿、目标在那边、局部树障长这样——下一个该到达的中间位姿在哪”。与 N3P 的“预测一个准备位姿”同构，区别是滚动调用形成序列。

3.2 问题形式化

环境。工作区 W ⊂ ℝ² 按分辨率 r = 0.1 m 离散为栅格集 G，先验占据图 M: G → {0,1}，取 1 表示树障占据；占据区域记 Occ(M) ⊂ W。地图约 30×30 m，离线已知——“先验”是与 LSP 一类 unknown-environment 工作划界的关键属性（§7.1）。

车辆。状态 x = (p, θ) ∈ SE(2)。阿克曼底盘，路径曲率约束 |κ| ≤ 1/ρmin（ρmin 由 pathplan 配置锁定，文中不出现裸数字）；车体足迹 B(x) 以双圆模型覆盖。

自由空间与可行路径。Xfree = {x ∈ SE(2) : B(x) ∩ Occ(M) = ∅}。可行路径 τ: [0,1] → Xfree，分段光滑、曲率处处合规、允许有限次方向切换。

规划查询。q = (M, xs, xg)，求可行 τ。求解质量两维：搜索代价（规划时间 T、节点扩展数 E）与路径质量（长度、方向切换、最小净空）。

RS 记号。RS(x, x′) 为连接两位姿的最短 Reeds-Shepp 曲线，按构造满足曲率约束，可行性只剩无碰一项：RSfree(x, x′) ⇔ 曲线全程位于 Xfree（沿曲线按 r 级步长采样做双圆碰撞检查）。

3.3 路线分解与学习目标

路线分解：给定 q，求有序子目标序列 (g₁, …, g_K)，gᵢ ∈ Xfree，使相邻对段内可被低代价连接（理想情形 RSfree 直连，一般情形预算 Nseg 内短段 HA*）。整条路径 τ = τ₀ ⊕ τ₁ ⊕ ⋯ ⊕ τ_K。

学习目标：一步预测器 π: ℝ⁴¹ → ℝ³（实现为 KNN 查表）——输入特征 f(x; xg, M)，输出车体系相对位姿 Δ̂ = (Δx, Δy, Δθ)；世界系子目标 ĝ = x ⊕ Δ̂（SE(2) 复合）。序列由滚动展开生成：gi+1 = gᵢ ⊕ π(f(gᵢ))。

监督来源：教师路径（vanilla HA*+RS 成功解）经 Algorithm 1 切分出 (f(gᵢ), Δᵢ) 样本对——标签由规划器自产、零人工标注。这是 self-supervised 限定语的全部含义，不引申。

4.2 标签提取：前向贪心 RS 可达分段（D4 的精确定义，Algorithm 1）

Algorithm 1  前向贪心 RS 可达分段（标签提取）
输入: 教师路径 P:[0,S]→X_free（弧长参数化, P(0)=x_s, P(S)=x_g）
输出: 子目标真值串 (g₁,…,g_K) 与样本集 {(f(gᵢ), Δᵢ)}
 1: g₀ ← P(0);  s₀ ← 0;  i ← 0
 2: while ¬( RS_free(gᵢ, x_g) ∧ len(RS(gᵢ, x_g)) ≤ L_max ):
 3:     Sᵢ ← { s ∈ (sᵢ, S] : RS_free(gᵢ, P(s)) ∧ len(RS(gᵢ, P(s))) ≤ L_max }
 4:     if Sᵢ = ∅ 或 max(Sᵢ) − sᵢ < L_min:                ▷ 标签失败分支
 5:         失败计数 +1；丢弃整条 P；return ∅
 6:     s_{i+1} ← max(Sᵢ);   g_{i+1} ← P(s_{i+1})           ▷ 取最远 RS 可达点
 7:     Δᵢ ← g_{i+1} ⊖ gᵢ                                   ▷ gᵢ 车体系下表达
 8:     emit 样本 (f(gᵢ), Δᵢ);   i ← i+1
 9: K ← i      ▷ 终止时剩余段 RS 直连，不产样本（与在线停止判据同构）

语义：每个子目标都是“从上一处一条解析曲线就能到”的最远点——与 N3P“从此处可便宜解”语义一致。

构造性质：对每个 i，RSfree(gᵢ, gi+1) 按构造成立 ⇒ 教师分布内、静态同图条件下，在线段内连接的解析扩展第一枪即可命中，HA* 仅作保险。滚动预测偏离 gᵢ 后该性质退化为近似，退化程度由子目标可达率量化（§5.4），由可行性校验 + fallback 兜底（§4.6）。

参数语义：Lmax（8 m）防开阔区单段超出特征视距 Rmax；Lmin（1.5 m）v1.1 起形式化为“单步推进下界”（第 4 行）——推进不足判标签失败，防密集区碎段；失败处理策略是开放项（§8.6），标签失败率为 pilot 观测哨。

复杂度（离线一次性）：第 3 行 max 谓词非单调、不能直接二分；按“Lmax 弧长初始窗口、向远端扫描+按需细化”实现。单条路径 O((S/Δs)·cRS)，cRS 为一次 RS 生成+碰撞校验（约 len/r 个采样点）；可按地图并行。

已知风险（AI 异议存档，D1 备注）：此规则标签落点常在开阔地、由求解器副产物决定，与局部几何特征关联弱于瓶颈规则。若 KNN 学不动，Contract 内的标签 ablation（解析分段 vs 瓶颈 vs 曲率边界）会暴露问题，届时按数据切换主规则（须 Contract v2）。

4.3 特征设计（环境抽象——森林版必须重造的部分，f ∈ ℝ⁴¹，全部车体系）

设计依据：ray-cast 净空轮廓是“无缝枚举版”的局部几何描述——不显式检测树缝，但缝在轮廓上是方向上的距离峰，KNN 度量可感知。这组特征就是我方的“环境抽象”（对应 N3P 的 4 参数闭式抽象），也是贡献点之一。

已知局限（与 §8.1 风险耦合）：Rmax 视距外结构不可见——若标签落点超出视距相关性，KNN 召回退化；轮廓对小角度抖动敏感，由 log 压缩与标准化部分缓解，由误差容忍 ablation 实证。

术语警戒（术语库 C-10）：ray-cast 是先验图上的几何查询，与传感器无关——写成“激光雷达/LiDAR 扫描”是事实错误；特征是手工几何量，写成“语义特征/嵌入/表征”同样错误。

4.4 学习模块

KNN(k=1) 主模型：库 D = {(fₙ, Δₙ)}；查询 π(f) = Δn*，n* = argminₙ d(f, fₙ)；反变换 ĝ = x ⊕ Δ̂。输出永远是教师数据中真实出现过的相对位姿（N3P 噪声免疫性质的保留形式）；注意它不保证在当前图无碰（样本可能来自他图），在线仍需可行性校验。

规模与开销：估算 2 000 图 × ~10 查询 × ~6 段 ≈ 1.2×10⁵ 样本，41 维 float32 ≈ 20 MB（N3P 的 KNN 47.8 MB，量级无忧）。41 维下 KD-tree 增益有限（高维退化），但即便线性扫描也在毫秒级——实测值进 §5.4 计时。

MLP（ablation）：4 层、~10⁵ 参数，回归 Δ；已知多模态平均风险（两缝样本均值落在缝间树干）——与 N3P 中 MLP 偶发不可行同源，论文可借此复刻其结论。

DQN 打分器不进 v1（Dr Sun 已授权放弃，红线只在任务级）。旧 MD-DQN 只以 RL 基线身份出场。

4.6 Fallback 阶梯（完备性保障）

级触发动作
F1RS(p→ĝ) 碰撞取 KNN 第 2…k 近邻重试（k≤5）
F2F1 全失败段内 HA*(p→ĝ) 限预算；仍失败则 HA*(p→goal) 试探
F3F2 失败 / 步数超限 / 连续 2 步无进展整题回退 vanilla HA*（N3P 同款兜底）
完备性论证（v1.1 显式化）：记预算内 vanilla HA* 可解查询集为 Qv。F3 规定方法失败时整题运行同配置 vanilla HA*，故成功集 ⊇ Qv——继承 vanilla 的完备性级别，不声称更强，也不声称最优性。最坏开销 T ≤ Toverhead + Tvanilla；fallback 触发率高 ⇒ 时间收益消失 ⇒ 恰为 Contract 失败信号①，机制与判据闭环。

4.5 在线推理循环（Algorithm 2）与开销分解

Algorithm 2  在线滚动推理
输入: 查询 q=(M, x_s, x_g)，样本库 D
输出: 可行路径 τ（方法解或 F3 回退解）
 1: p ← x_s;  τ ← ∅;  K_max ← ⌈2‖p_s−p_g‖/L_min⌉
 2: for step = 1..K_max:
 3:     if RS_free(p, x_g):  return τ ⊕ RS(p, x_g)          ▷ 停止判据
 4:     ĝ ← p ⊕ π(f(p))                                     ▷ KNN 预测 + 反变换
 5:     if ¬RS_free(p, ĝ):  ĝ ← F1(p)                       ▷ 第 2..k 近邻重试
 6:     if F1 全失败:  转 F2/F3（§4.6）
 7:     τ_seg ← HA*(p → ĝ | 解析扩展优先, 预算 N_seg)        ▷ 段内连接
 8:     if τ_seg 失败:  转 F2/F3（§4.6）
 9:     τ ← τ ⊕ τ_seg;   p ← ĝ
10:     if ‖p − p_g‖ 连续 2 步不降:  转 F3                   ▷ 无进展哨
11: 转 F3（步数超限）

停止判据与标签终止条件同构（都是“RS 可直达”）——机制与标签语义闭环。v1 不做输出平滑后处理，与基线公平。

环节次数上界单次成本
特征提取Kmaxnray 次栅格步进 O(Rmax/r) + 环带统计 O((Rmax/r)²)
KNN 查询Kmax上界 O(d·N)，实测毫秒级（§4.4）
RS 可行性校验k·KmaxO(len/r) 采样碰撞检查
段内 HA*Kmax≤ Nseg 次扩展；教师分布内典型为解析扩展直中
末段 RS 直连1O(len/r)
与 vanilla 的对照机制：vanilla HA* 扩展数随距离与密度急剧增长（实测痛点）；F-N3P 将其替换为“K 段 × 每段预算 Nseg 的搜索 + 常数级学习开销”。这是机制陈述、不作先验断言，由 §5.4 指标矩阵实证检验。

5. 实验设计（v1 范围，D3）

5.1 场景矩阵与数据划分

难度三轴（形式化）：树密度 λ（单位面积树数）× 最窄缝宽与车宽之比 wmin/wveh × 起终欧氏距离 dsg，对应 N3P Easy/Complex/Extreme 精神，至少 3×3 桶有效覆盖；各轴切点待 pilot 标定（§8.7），标定后写入 Contract，此处不预设数字。

数据划分：训练 ~2 000 张程序化森林（多密度多种子）；验证 = 同分布新种子；测试 = ①未见同分布图 ②OOD 密度桶（外推）③真实 SLAM 占据图（RealMap 资产，仅测试）。种子纪律：学习模块 ≥5 种子；每桶 ≥100 评测场景；报 min/mean/median/P95（N3P 口径）。

5.5 计时与统计协议（v1.1 新增）

计时：单线程、同机、负载隔离；DP 预计算按 N3P 口径计入每次查询；学习方开销全部计入——不允许出现“裸搜索时间”对比。统计：≥5 种子 × 每桶 ≥100 场景；主表报 median 与 P95，附 min/mean；种子间报中位数与极差。显著性检验（建议项，草案）：逐查询配对 Wilcoxon 符号秩（时间）+ bootstrap 置信区间（成功率差）——是否纳入由 Dr Sun 立约时定夺。

9. Contract 草案要素（立约时由 Dr Sun 锁数字）

Hypothesis（草案）：Complex/Extreme 桶上，F-N3P 相对 vanilla HA*：median 规划时间缩减 ≥50%，成功率不降（≥−2 pp），路径长度膨胀 ≤5%；且相对最强规则分解基线（Voronoi waypoint HA*）在 hard 桶帕累托不劣。
Success signal（草案）：上述三条在未见程序化图与真实地图上同时成立，≥5 种子中位数达标。
Failure signal（独立定义，草案）：任一成立——① fallback 触发率 >30% 且时间收益消失；② OOD 桶成功率相对 vanilla HA* 跌 >5 pp；③ 与 hand-crafted 瓶颈 waypoint 无显著差异（说明“学习”不必要）；④ 真实地图时间收益 <20%。
